About this Workshop

A hands-on introduction to Python for researchers at the University of Twente. Using the Software Carpentry "Programming with Python" curriculum, participants analyse real clinical trial data (arthritis inflammation), visualise results, and build reusable scripts — no prior programming experience required.

Quick Setup

  1. Clone or download this repository into a folder called swc-python on your Desktop.
  2. Create and activate a virtual environment: 
    python -m venv venv
# macOS / Linux
source venv/bin/activate
# Windows
venv\Scripts\activate
  3. Install dependencies: 
    pip install -r requirements.txt
  4. Launch Jupyter Lab: 
    jupyter lab

For full setup instructions see Python_Day1/README.md.
